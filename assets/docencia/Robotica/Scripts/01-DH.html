Transformación de Denavit-Hartenberg

Función de MATLAB para generar la matriz de transformación homogénea asociada a los parámetros de Denavit-Hartenberg.

Uso

La función recibe los cuatro parámetros theta, d, a y alpha, y devuelve la matriz homogénea T.

Puede utilizarse tanto con valores numéricos como con variables simbólicas. Cuando los parámetros son numéricos, los ángulos se interpretan en grados.

MATLAB 
function T = DH(theta, d, a, alpha)

if isa(theta,'sym')
    ct = cos(theta);
    st = sin(theta);
else
    ct = cosd(theta);
    st = sind(theta);
end

if isa(alpha,'sym')
    ca = cos(alpha);
    sa = sin(alpha);
else
    ca = cosd(alpha);
    sa = sind(alpha);
end

T = [ct, -ca*st,  sa*st, a*ct;
     st,  ca*ct, -sa*ct, a*st;
     0,   sa,     ca,    d;
     0,   0,      0,     1];

end
