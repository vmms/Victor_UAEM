Objetivo

Analizar los conceptos básicos de los sistemas robóticos mediante el estudio del estado del arte y los estándares internacionales, para comprender los diferentes tipos de robots y su seguridad.

Temas

  • 1.1 Antecedentes de robótica
  • 1.2 Terminología
  • 1.3 Aplicaciones y estado del arte
  • 1.4 Tipos de robots: manipuladores y móviles
  • 1.5 Aspectos de seguridad y normas

Objetivo

Analizar el funcionamiento de los componentes físicos de los robots para comprender su estructura, movilidad y control.

Arduino / C++ 
const int trigPin = 9;
        const int echoPin = 10;
        
        void setup() {
            pinMode(trigPin, OUTPUT);
            pinMode(echoPin, INPUT);
            Serial.begin(9600);
        }
        
        void loop() {
            long duration, distance;
        
            // Envía un pulso ultrasónico
            digitalWrite(trigPin, LOW);
            delayMicroseconds(2);
            digitalWrite(trigPin, HIGH);
            delayMicroseconds(10);
            digitalWrite(trigPin, LOW);
        
            duration = pulseIn(echoPin, HIGH);
            distance = (duration * 0.034) / 2;
        
            Serial.print("Distancia: ");
            Serial.print(distance);
            Serial.println(" cm");
        
            delay(1000);
        }
